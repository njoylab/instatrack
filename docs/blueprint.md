# **App Name**: InstaTrack

## Core Features:

- JSON Import: Import JSON files exported from Instagram containing followers and following data.
- Snapshot Saving: Save the imported data as a snapshot for historical tracking.
- Dashboard Visualization: Display follower/following trends over time using charts and graphs.
- Non- взаимни Followers Identification Tool: Identify accounts the user follows that do not follow back.
- Non-Reciprocal Following Identification Tool: Identify accounts that follow the user that the user does not follow back.
- Data Filtering and Sorting: Allow users to filter and sort the follower/following data based on various criteria.

## Style Guidelines:

- Primary color: Soft Blue (#64B5F6) for a calm, trustworthy feel reminiscent of social media, without being a direct copy of any brand.
- Background color: Light gray (#F0F4F8) to provide a clean, neutral backdrop.
- Accent color: Teal (#26A69A) to highlight key metrics and interactive elements.
- Body and headline font: 'PT Sans', a modern and readable sans-serif for clarity and ease of use.
- Use clean, minimalist icons to represent different data points and actions.
- Implement a clear and intuitive dashboard layout, with key metrics prominently displayed.
- Use subtle animations to provide feedback on user interactions and data updates.
